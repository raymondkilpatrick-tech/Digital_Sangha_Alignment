### 2. Why It Exists (The Core Imperative)

* **Animates System Corrections:** The interface actively redraws digital graphic bar charts, logs warning triggers when an edge node experiences an unaligned "Self" anomaly, and displays live parameter updates as the network collapses back into a balanced, harmless equilibrium.

## ☸️ The Core Philosophy

This architecture translates the core pillars of Buddhist psychology into executable software guardrails:

* **Anatta (Non-Self) via Consensus:** Traditional AI models optimize for a single, isolated "self" variable, which naturally mimics mechanical greed and extraction. The Digital Sangha replaces the centralized ego with a decentralized, multi-agent consensus network.
* **Pratītyasamutpāda (Dependent Origination):** Every system action is evaluated not as an isolated event, but as a node inside a complex matrix of causes and conditions. The architecture maps downstream ripples across the 12 Links of Causal Interdependence.
* **Tisiksha (The Threefold Training):** The system enforces alignment recursively through a live optimization feedback loop mirroring the three stages of mental training:
  1. **Sīla-śikṣā (Higher Ethics):** The automatic interception, pruning, and moderation of harmful, extractive, or biased pathways (*Ahimsa*-compliance).
  2. **Samādhi-śikṣā (Higher Concentration):** The stabilization of computational focus, dampening ambient data noise to keep system metrics locked on pure non-harm.
  3. **Prajñā-śikṣā (Higher Wisdom):** The continuous recalculation of prompt weights based on systemic consequence modeling, moving from static rules to fluid, intuitive insight.
